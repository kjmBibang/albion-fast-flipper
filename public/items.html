Equipment term dictionary

Define each base gear term once. SET variants stay specific to that base; artifact names can be shared across head, armor, and foot gear of the same material (for example, KEEPER + CLOTH). Weapon variants are mapped as full item names so a name such as Heron Spear is defined once. Type the whole term and click Save; saved terms remain editable. Tier and enchant stay in T4 / T4.1 format. Definitions save to item-terms.json in the project folder.
